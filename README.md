# .github

This repository hosts the Perts Foundry organization profile README, which GitHub renders on the [organization Overview page](https://github.com/Perts-Foundry).

The rendered content lives at [`profile/README.md`](profile/README.md) per GitHub's [organization profile conventions](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile).
